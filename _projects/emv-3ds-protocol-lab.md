The EMV 3-D Secure Protocol Lab is an open, vendor-neutral reference designed to make 3DS behavior easier to inspect, compare, and explain.

It focuses on:

- browser and app flow visualization across published spec versions
- protocol message structure and trust-boundary interpretation
- reproducible debugging support for security researchers, payment teams, and educators

This project reflects the kind of work I want this portfolio to foreground: payment-security research that is technically careful, practically usable, and legible to both engineering and risk stakeholders.
